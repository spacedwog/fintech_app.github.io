# DPIA — Avaliação de Impacto à Proteção de Dados

**Versão:** 1.0  
**Data:** 2026-08-14

## Escopo avaliado

Tratamento de dados pessoais para autenticação, operação financeira pessoal e sincronização em nuvem.

## Riscos de privacidade identificados

1. Exposição indevida de dados por falha de isolamento entre contas.
2. Coleta excessiva de dados sem necessidade funcional.
3. Uso de cookies não essenciais sem consentimento válido.

## Medidas mitigatórias

- Isolamento por `tenant_id` e controle por papéis.
- Coleta mínima de dados para operação do serviço.
- Consent Mode com padrão `denied` até aceite explícito.
- Exportação e exclusão self-service para direitos do titular.

## Conclusão

Com os controles atuais e governança documentada, o risco residual foi classificado como **médio**, exigindo monitoramento trimestral e revisão sempre que houver nova integração externa relevante.
