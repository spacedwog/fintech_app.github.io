# Controle de Não Conformidades (ISO 9001)

**Versão:** 2.0  
**Data:** 2026-08-14

## Fluxo

1. Registrar não conformidade (descrição, impacto, origem).
2. Classificar severidade (alta/média/baixa).
3. Definir ação corretiva com responsável e prazo.
4. Validar eficácia da correção.
5. Encerrar com evidência.

## Campos obrigatórios do registro

- ID
- Data
- Requisito afetado
- Evidência
- Responsável
- Prazo
- Status
