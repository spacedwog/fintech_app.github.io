Conectar Mercado Pago

Este painel é 100% estático — por segurança, o Access Token do Mercado Pago nunca é enviado nem chamado direto do navegador. A integração de verdade roda fora daqui, por orcamento_agent/mp_expenses.py + mp_reconcile.py (manual, agendado, ou automático via GitHub Actions). Este modal só ajuda a gerar a configuração e mostra o status real da última execução.

Status da automação

Carregando…

Gere em developers.mercadopago.com.br → Suas integrações → Credenciais. Usado só neste navegador, agora, para montar o arquivo de configuração — não é enviado a lugar nenhum nem fica salvo depois de gerar o download.

Depois de baixar: coloque os dois arquivos em orcamento_agent/ (substituindo mp_expenses_config.json e mp_reconcile_config.json) e rode python3 mp_reconcile.py && python3 mp_expenses.py. Para automatizar sem depender do seu computador, configure os mesmos valores como Secrets do repositório no GitHub (Settings → Secrets and variables → Actions) — veja orcamento_agent/LEIA-ME.md e .github/workflows/mercado-pago-sync.yml.
