# Contribuindo com o Fintech Spacecworp

Obrigado por considerar contribuir com este projeto! 🎉

## Como contribuir

Você pode contribuir de várias formas:

- Reportando bugs
- Sugerindo melhorias
- Melhorando documentação
- Enviando correções de código

## Antes de abrir uma contribuição

1. Verifique se já existe issue relacionada.
2. Descreva claramente o problema e o impacto.
3. Para mudanças maiores, abra uma issue antes para alinhamento.

## Fluxo recomendado

1. Faça um fork do repositório.
2. Crie uma branch para sua mudança.
3. Faça alterações pequenas e objetivas.
4. Garanta que não incluiu segredos (tokens/chaves/senhas).
5. Abra um Pull Request com contexto claro do que mudou.

## Padrões para Pull Request

- Descreva o objetivo da mudança.
- Liste os principais arquivos alterados.
- Explique como validar a alteração.
- Mantenha o escopo focado (evite mudanças não relacionadas).

## Código de Conduta

Ao participar deste projeto, você concorda em seguir o [Código de Conduta](./CODE_OF_CONDUCT.md).

## Segurança

Se você identificar uma vulnerabilidade, **não abra issue pública**. Siga o processo em [SECURITY.md](./SECURITY.md).
