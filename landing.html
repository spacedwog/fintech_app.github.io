Segurança e transparência

Como cuidamos dos seus dados

Senhas armazenadas com hash PBKDF2 + SHA-256, nunca em texto puro.

Os dados ficam salvos no seu próprio navegador — ideal para uso pessoal e demonstrações.

Cobranças Pix seguem o padrão oficial do Banco Central (BR Code com CRC16).

Por ser 100% client-side, o isolamento entre empresas é lógico, não uma fronteira de segurança real, e a confirmação de pagamento Pix é feita pelo próprio usuário. Ideal para demonstração, protótipo ou uso pessoal.

FAQ

Perguntas frequentes

O que é o Fintech SaaS?

É um painel de controle financeiro para empresas: registro de despesas, relatórios mensais, orçamento com alertas e pagamento via Pix real, tudo em um único lugar.

Preciso de cartão de crédito para criar conta?

Não. O plano Free é gratuito e dá acesso completo ao painel, com limite de 6 despesas por dia.

Como funciona o pagamento via Pix?

O QR Code e o código copia-e-cola seguem o padrão oficial do Banco Central (BR Code). A confirmação de que o pagamento foi feito é declarada pelo próprio usuário — não há verificação bancária automática.

Onde meus dados ficam salvos?

No armazenamento local do seu navegador (localStorage). Isso é ótimo para uso pessoal e demonstrações, mas os dados não saem do dispositivo onde foram criados.

Posso usar em mais de um dispositivo?

Ainda não. Como os dados ficam no navegador, eles não sincronizam automaticamente entre computadores ou navegadores diferentes.
