Segurança e transparência

Como cuidamos dos seus dados

Senhas armazenadas com hash PBKDF2 + SHA-256, nunca em texto puro.

Seus dados sincronizam automaticamente com o Firebase, com uma cópia local como reserva offline.

Cobranças Pix seguem o padrão oficial do Banco Central (BR Code com CRC16).

Um agente local opcional cruza os pagamentos com a API do Mercado Pago e confirma automaticamente, sem precisar reabrir o app.

Em arquitetura fullstack web, o isolamento entre contas usa frontend + backend em nuvem. A confirmação de pagamento Pix combina até duas checagens automáticas — leitura do comprovante por IA (OCR local) e cruzamento com o Mercado Pago — mas nenhuma das duas é um webhook bancário em tempo real; quando nenhuma confirma, o pagamento fica marcado para revisão manual. Ideal para demonstração, protótipo ou uso pessoal.

FAQ

Perguntas frequentes

O que é o Fintech Spacecworp?

É um painel de controle financeiro pessoal: registro de despesas, relatórios mensais, orçamento com alertas e pagamento via Pix real, tudo em um único lugar.

Preciso de cartão de crédito para criar conta?

Não. O plano Free é gratuito e dá acesso completo ao painel, com limite de 6 despesas por dia.

Como funciona o pagamento via Pix?

O QR Code e o código copia-e-cola seguem o padrão oficial do Banco Central (BR Code). A confirmação inicial pode ser declarada pelo usuário e reforçada por OCR local do comprovante; adicionalmente, um agente opcional pode reconciliar pagamentos reais fora do navegador.

O sistema já paga minhas contas por mim?

Ainda não. Hoje você registra os pagamentos do mês e usa o Pix real para pagar manualmente. A ideia é evoluir para o sistema realizar o pagamento automaticamente por você — isso está no roadmap para uma versão futura.

Dá para importar meu orçamento de uma planilha já pronta?

Sim. Envie o arquivo (.xlsx/.xls/.csv) na tela "Importar Orçamento" — a leitura acontece no navegador e integra o fluxo fullstack com persistência em nuvem. Se a planilha fugir do padrão, dá para configurar manualmente onde estão as colunas em um layout que fica salvo para os próximos uploads.

Como o Mercado Pago confirma meus pagamentos automaticamente?

Além da conferência do comprovante por IA na hora, um agente local opcional cruza o histórico de pagamentos do painel com os pagamentos reais aprovados na sua conta do Mercado Pago (por valor e data) e marca como verificado quando encontra uma correspondência clara. Não é um webhook em tempo real — depende de rodar (ou agendar) esse agente fora do navegador.

É possível integrar com legado IBM COBOL?

Sim. A integração é feita por uma camada intermediária fora do front-end, que exporta eventos financeiros para o agente orcamento_agent/cobol_bridge.py. Esse agente reconcilia pagamento, status de quitação e histórico de liquidação com idempotência por evento.

Onde meus dados ficam salvos?

No banco de dados na nuvem (Firebase/Firestore), com o armazenamento local do seu navegador (localStorage) como reserva automática caso o Firebase esteja indisponível ou você esteja offline. Assim que a conexão volta, tudo é sincronizado.

Posso usar em mais de um dispositivo?

Sim, quando o Firebase está configurado: os dados sincronizam entre computadores e navegadores diferentes. Sem essa configuração, o app funciona normalmente só com localStorage (dados presos ao dispositivo), como antes.
